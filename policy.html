プライバシーポリシーとご利用にあたって

制定日：2026年10月8日

プライバシーポリシー

集める情報

譜めくりは、利用者の個人情報を集めません。アカウント登録も必要ありません。

楽譜などのデータの保存先

取り込んだ楽譜、書き込み、フォルダ、セットリスト、設定は、お使いの端末のブラウザの保存領域にだけ保存されます。開発者を含む第三者のサーバーに送られることはありません。

アクセス解析・広告

アクセス解析ツール、広告、Cookie による追跡は使っていません。

通信について

アプリを開くときや更新するときに、アプリのファイルを GitHub Pages（GitHub, Inc. が提供するサービス）から読み込みます。このとき GitHub が、IPアドレスなどのアクセス記録を残す場合があります。詳しくは GitHub のプライバシーに関する声明 をご覧ください。楽譜のデータは、この通信には含まれません。

カメラ・写真

紙の楽譜を取り込むときだけ、端末の標準のカメラ画面や写真の選択画面を使います。撮影した画像の補正は端末の中で行い、外部には送りません。

共有

「共有」や「PDF出力」を選んだときだけ、端末の共有機能を通して、利用者が選んだ相手やアプリにファイルが渡されます。

改定

このポリシーを変更するときは、このページでお知らせします。

ご利用にあたって

  • 譜めくりは無料で提供しています。動作や内容について保証はなく、データの消失など、利用によって生じた損害について開発者は責任を負いません。大切な楽譜は「設定 → すべての楽譜をバックアップ」で定期的に書き出してください。
  • 取り込んだり共有したりする楽譜は、著作権法で認められた範囲（個人での練習など）でご利用ください。市販の楽譜や著作権のある楽譜を、権利者の許可なく配布・公開しないでください。
  • アプリの内容は、予告なく変更・終了することがあります。

お問い合わせ

不具合の報告やご意見は、GitHub の Issues へお寄せください（GitHub アカウントが必要です）。
